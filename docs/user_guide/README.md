# PyBerryPLC User Guide

This user guide explains how to build PLC-like Python applications with
`pyberryplc-platform`.

The guide is organized as a sequence of chapters. Each chapter builds on the
previous one and introduces only the concepts needed for that application
level.

## Chapters

1. [Building a Single-PLC Application](01_single_plc.md)
2. [Single-PLC Application With a Remote Device](02_single_plc_remote_device.md)
3. [Multiple-PLCs Application](03_multiple_plcs.md)

Motion-control functionality is intentionally left out of this guide for now.
